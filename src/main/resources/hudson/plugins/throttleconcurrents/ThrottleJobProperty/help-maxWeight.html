Maximum total weight capacity for this physical machine. Must be a valid number (1 or greater).

Warning: This configured value is enforced strictly and will override any capacity values declared via node labels (e.g., THROTTLE_SHARED_HARDWARE_MAX). If set too low, it may block agents that require more weight points than the configured capacity allows.

Conversely, when capacity is discovered only from node labels (without a configured value here), the effective minimum will be at least the weight of the heaviest known agent on that machine, so agents are never blocked by an unrealistically low auto-discovered capacity.
