Multiplier applied to the heaviest agent weight when no other capacity is known for a machine.

The effective capacity is computed as: heaviest agent weight × factor.

Examples:

  • If agents on ServerA have weights 2 and 3, and the factor is 5, the capacity is 3 × 5 = 15.
  • If the factor is 1, the capacity equals the heaviest agent weight (only that single agent can run at a time, or maybe a few smaller ones).

Set to 0 (default) to disable the fallback. When disabled, machines without an explicitly configured capacity (via node labels or the machine capacity list above) will not be throttled -- any available executor accepts work immediately.

This fallback is applied only when no other capacity source is found: no external provider, no configured machine capacity, and no "Label Key for Machine Assignment" (defaults to THROTTLE_SHARED_HARDWARE_MAX) label on any node for that machine.
